# Peter Rabbit Boy/Girl Color Options

## Volusion import (do this first)
1. Inventory → Import/Export → **Options** → import `Options_Import.csv` (creates Girl=1213, Boy=1214 in color category 23).
2. Import `Options_Apply.csv` OR Products import `Products_Import.csv` to attach options to:
   - SAR-PTR-RBT-BMBU-RYN-MSLN (full)
   - SAR-PTR-RBT-BMBU-RYN-MSLN-02 (mini)

## Images

- {CODE}-1213-T.jpg / -S.jpg (Girl hero/swatch)
- {CODE}-1214-T.jpg / -S.jpg (Boy hero/swatch)
